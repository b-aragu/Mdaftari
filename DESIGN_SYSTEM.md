# DESIGN_SYSTEM.md — Mdaftari

## Design Philosophy

- Clarity over decoration
- Visibility over beauty
- Readability over branding
- Outdoor-first UI

---

## Brand Theme

**Theme Name:** Teal Trust

Teal represents:
- Trust (blue)
- Growth (green)
- Kenyan cultural familiarity

---

## Typography

Font stack:
- System UI
- Roboto (Android)

Sizes:
- Amounts: 32px / Black
- Headings: 24px / Black
- Body: 14px / Semibold
- Labels: 12px / Bold

---

## Outdoor Mode (Critical)

Triggered by:
- Ambient light sensor
- Manual toggle
- GPS context

Outdoor Mode Rules:
- White background
- Black text
- No gradients
- No shadows
- Thick borders (4px)
- Neo-brutalist appearance

Contrast:
- 21:1 minimum

---

## Buttons

### Primary
- Amber gradient
- Rounded (12px)
- High padding

### Outdoor Override
- Black background
- Yellow text
- Thick black border
- Hard shadow

---

## Cards

Standard:
- Soft shadow
- Rounded

Outdoor:
- Solid black border
- Hard offset shadow

---

## Accessibility

- WCAG 2.2 compliant
- Color never used alone
- Icons + labels always
- Touch targets ≥44px
- Screen-reader labels required
